## MODIFIED Requirements

### Requirement: Режимы симулятора и боевого API
The system SHALL поддерживать два режима окружения для работы с Директом: симулятор рекламного рынка и боевой API Директа. Режим окружения задаётся конфигурацией, а не пользователем, и определяет, куда идёт режим бизнеса «Яндекс Директ». Режим бизнеса «Симуляция» (`simulation-mode`) от режима окружения не зависит: он выбирается пользователем и всегда работает на симуляторе с виртуальным временем, в том числе в боевом окружении. Локальная разработка, CI и staging SHALL работать в режиме симулятора. Конфигурация с неизвестным режимом, в том числе с прежним значением режима песочницы, MUST отклоняться при старте с явной ошибкой.

Плашки тестового стенда над страницами MUST NOT быть ни в одном режиме. О ненастоящей рекламе говорят там, где это важно для решения: у бизнеса в режиме «Симуляция» — пульт симуляции со своей пометкой (`simulation-mode`), а у бизнеса в режиме «Яндекс Директ» на стенде с симулятором — шаг запуска мастера, который прямо говорит, что используется тестовая копия Директа и настоящая реклама недоступна (`business-onboarding`).

#### Scenario: Окружение разработки
- **WHEN** сервис запущен в режиме симулятора
- **THEN** ни один вызов не уходит в API Директа, кампании создаются в симуляторе, а плашки тестового стенда на страницах нет

#### Scenario: Устаревшая конфигурация песочницы
- **WHEN** сервис запускается с режимом песочницы, оставшимся от прежней конфигурации
- **THEN** worker и web не стартуют и сообщают, что режим песочницы больше не поддерживается и допустимы только режимы симулятора и боевого API

#### Scenario: Боевой режим
- **WHEN** сервис запущен в режиме боевого API
- **THEN** все вызовы бизнесов в режиме «Яндекс Директ» идут в боевой API Директа от имени подключённого аккаунта пользователя

#### Scenario: Симуляция в боевом окружении
- **WHEN** в боевом окружении пользователь запускает бизнес в режиме «Симуляция»
- **THEN** кампании этого бизнеса создаются только в симуляторе, ни один вызов не уходит в API Директа, а бизнесы в режиме «Яндекс Директ» продолжают работать с боевым API

#### Scenario: Стенд без плашки
- **WHEN** владелец бизнеса в режиме «Яндекс Директ» открывает мастер на стенде с симулятором
- **THEN** плашки «Тестовый стенд» над страницей нет, а шаг запуска говорит, что используется тестовая копия Директа и настоящая реклама недоступна
