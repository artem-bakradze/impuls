## MODIFIED Requirements

### Requirement: Режимы симулятора и боевого API
The system SHALL поддерживать два режима окружения для работы с Директом: симулятор рекламного рынка и боевой API Директа. Режим окружения задаётся конфигурацией, а не пользователем, и определяет, куда идёт режим бизнеса «Яндекс Директ». Режим бизнеса «Симуляция» (`simulation-mode`) от режима окружения не зависит: он выбирается пользователем и всегда работает на симуляторе с виртуальным временем, в том числе в боевом окружении. Локальная разработка, CI и staging SHALL работать в режиме симулятора. Конфигурация с неизвестным режимом, в том числе с прежним значением режима песочницы, MUST отклоняться при старте с явной ошибкой. В режиме симулятора интерфейс MUST постоянно показывать плашку «Тестовый стенд — Яндекс Директ не подключён, реклама не показывается»; на экранах бизнеса в режиме «Симуляция» её заменяет пульт симуляции со своей пометкой, чтобы на экране не было двух плашек о ненастоящей рекламе.

#### Scenario: Окружение разработки
- **WHEN** сервис запущен в режиме симулятора
- **THEN** ни один вызов не уходит в API Директа, кампании создаются в симуляторе, а на каждой странице видна плашка тестового стенда или, у бизнеса в симуляции, пульт симуляции

#### Scenario: Устаревшая конфигурация песочницы
- **WHEN** сервис запускается с режимом песочницы, оставшимся от прежней конфигурации
- **THEN** worker и web не стартуют и сообщают, что режим песочницы больше не поддерживается и допустимы только режимы симулятора и боевого API

#### Scenario: Боевой режим
- **WHEN** сервис запущен в режиме боевого API
- **THEN** все вызовы бизнесов в режиме «Яндекс Директ» идут в боевой API Директа от имени подключённого аккаунта пользователя, а плашка тестового режима не показывается

#### Scenario: Симуляция в боевом окружении
- **WHEN** в боевом окружении пользователь запускает бизнес в режиме «Симуляция»
- **THEN** кампании этого бизнеса создаются только в симуляторе, ни один вызов не уходит в API Директа, а бизнесы в режиме «Яндекс Директ» продолжают работать с боевым API
