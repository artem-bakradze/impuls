## ADDED Requirements

### Requirement: Картинки в Директе
The system SHALL при запуске загружать картинку каждого объявления на сайтах-партнёрах в библиотеку изображений рекламодателя в Директе (`ad-creatives`, «Картинки объявлений на сайтах-партнёрах»). Объявление SHALL создаваться текстово-графическим с этой картинкой. Одна картинка SHALL загружаться один раз: вариант объявления для проверки использует картинку исходного и не загружает её заново.

Картинка, которую не приняла модерация, SHALL обрабатываться так же, как отклонённый текст: событие модерации с причиной и исправленный вариант (`ad-agent`, «Ходы агента»). Симулятор рекламного рынка SHALL принимать картинки так же, как Директ, но без запросов к API Директа. В симуляции картинка видна на «Рекламе» и на статистику не влияет.

Загрузка и создание объявления SHALL идти через исполнитель команд. Сбой загрузки картинки повторяется по правилам временных ошибок Директа; если картинку загрузить так и не удалось, объявление MUST NOT создаваться без неё молча: запуск сообщает об ошибке простыми словами.

#### Scenario: Запуск с картинками
- **WHEN** владелец запускает рекламу в Директе с двумя объявлениями на сайтах-партнёрах
- **THEN** обе картинки загружены в библиотеку изображений рекламодателя, а оба объявления созданы текстово-графическими с ними и отправлены на модерацию

#### Scenario: Вариант с той же картинкой
- **WHEN** сервис создаёт вариант объявления на сайтах-партнёрах для проверки
- **THEN** вариант создан с картинкой исходного объявления, и новой загрузки картинки нет

#### Scenario: Картинка в симуляции
- **WHEN** владелец запускает симуляцию с объявлениями на сайтах-партнёрах
- **THEN** объявления создаются на учебном рынке с картинками, в API Директа не уходит ни одного запроса, а лист объявлений показывает картинки

#### Scenario: Картинку отклонила модерация
- **WHEN** Директ отклонил объявление из-за картинки
- **THEN** владелец видит причину простыми словами, а сервис готовит исправленный вариант, как при отклонённом тексте
