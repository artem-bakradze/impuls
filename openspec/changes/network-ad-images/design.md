## Context

Мотивация — в proposal.md.

**Как устроено сейчас:**
- Тексты объявлений готовит `CreativeEngine` (`packages/agent/src/creatives.ts`): `TemplateCreativeEngine` без модели или `LlmCreativeEngine`. Выбор — `CREATIVES=template|openai` воркера.
- Мастер вызывает задание `generate_creatives` (`apps/worker/src/web-jobs.ts`). Черновик хранит объявления как `{ title, text }` в `card.onboarding` (web).
- Запуск (`launch.ts`) создаёт кампании и объявления через `AdPlatform.createAd({ campaignId, title, text, landingUrl })`. Адаптер Директа шлёт `ads.add` с `TextAd`.
- Вариант для проверки делает `CreativeEngine.variant` и создаёт исполнитель командой.
- В превью мастера на месте картинки объявления на сайтах-партнёрах стоит значок (`AdPreview`, `PictureOutlined`).
- По ключу доступны модели картинок `gpt-image-*` (проверено бесплатным `GET /v1/models` 2026-11-05).

## Goals / Non-Goals

**Goals:**
- одна картинка на объявление на сайтах-партнёрах, от мастера до Директа;
- бесплатный и детерминированный шаблон для стенда и автотестов;
- платные картинки — по лимиту и только из публичных данных.

**Non-Goals:**
- смена картинки после запуска (команда исполнителя для живого объявления — отдельное изменение);
- фото владельца;
- широкий формат 16:9 и видео;
- картинки в поиске.

## Decisions

**1. Порт `ImageEngine` рядом с `CreativeEngine`.** Сигнатура: `draw(facts: ImageFacts, seed: number): Promise<AdImage>`, где `AdImage = { png: Uint8Array; width; height; source: "generated" | "template" }`. `ImageFacts` — допуск по полям: категория, услуги, район, заголовок объявления. Остального в типе нет, поэтому личные данные не могут попасть в запрос.
- `OpenAiImageEngine` — Images API с моделью `OPENAI_IMAGE_MODEL`, квадрат 1024 × 1024, ответ в base64. Промпт по-английски: тема бизнеса и запрет на текст, цифры, логотипы и людей крупным планом.
- `TemplateImageEngine` — PNG 1024 × 1024 без зависимостей: градиент по оттенку от хэша категории и узор из простых фигур по `seed`. Кодирование — `node:zlib.deflateSync` и CRC32 по стандарту PNG.

Выбор движка тот же, что для текстов: `CREATIVES=openai` → модель, иначе шаблон. Альтернатива — SVG с растеризацией (`resvg`) — отклонена: новая нативная зависимость ради простых фигур.

**2. Хранение — таблица `ad_images`.** Миграция добавляет:
- таблицу `ad_images`: `id`, `business_id`, `png bytea`, `width`, `height`, `source`, `seed` (вариант шаблона: «Другая картинка» берёт следующий), `created_at`;
- в `ads` — `image_id` и `image_hash` (хэш картинки в библиотеке площадки).

Хэш хранится у объявления, а не у картинки: у учебного рынка и у Директа библиотеки разные, и одна картинка после «Запустить по-настоящему» загружается в Директ заново. Вариант для проверки берёт хэш исходного объявления той же площадки.

Черновик мастера хранит `imageId` у объявлений на сайтах-партнёрах. Web отдаёт картинку через `GET /api/ad-images/:id`: проверяет, что картинка принадлежит бизнесу пользователя, отвечает `image/png` с долгим кэшем (id не меняется). Мини-сайт и его домен не затрагиваются. Альтернатива — S3-хранилище мини-сайтов — отклонена: картинка — часть черновика и рекламы, она не публичная страница и нужна до запуска.

**3. Генерация и «Другая картинка» — задания воркера.**
- Картинки рисует отдельное задание `draw_ad_images` (без режима, как `generate_creatives`), которое мастер ставит сразу после текстов. Так платная картинка не задерживает тексты и не упирается в время ожидания мастера, а на месте картинки видно «Рисуем картинку…». Внутри задания картинки рисуются параллельно, не больше 3 одновременно.
- Первая картинка объявления получает `seed` по его заголовку, поэтому шаблон для того же объявления одинаков. «Другая картинка» и «Попробовать ещё раз» — то же задание с текущей картинкой объявления: `seed` следующий, текст не меняется.
- Картинка другого бизнеса в запросе считается отсутствующей.
- Сбой модели — это задокументированный деградированный режим спецификации: шаблон и сообщение. Повтора без ведома нет: повтор — «Попробовать ещё раз» владельца.
- Лимит — число платных картинок на бизнес за календарный месяц по `ad_images.source = 'generated'`. Конфигурация `IMAGE_MONTHLY_LIMIT` и цена `IMAGE_PRICE_RUB` обязательны при `CREATIVES=openai` (fail-fast на старте). Цена нужна для учёта затрат в логах и CLI `costs`.

**4. Платформа.** В контракт `AdPlatform` добавляются:
- `uploadImage(png, name): Promise<string>` — хэш изображения;
- `NewAd.imageHash?: string` и `PlatformAd.imageHash: string | null`.

Реализации:
- адаптер Директа: `adimages.add` (`ImageData` в base64, `Name`) → `AdImageHash`; `ads.add` с `TextAd.AdImageHash` для кампаний сайтов-партнёров;
- симулятор: детерминированный хэш от байтов, хранит его у объявления.

`launch.ts` загружает картинку каждого объявления один раз, до создания первой кампании, и кладёт хэш в `ads.image_hash`. Так отказ Директа принять картинку останавливает запуск целиком: ничего не создано, а владелец видит «Яндекс не принял картинку объявления, поэтому реклама не запущена…» (`IMAGE_UPLOAD_FAILED`). Временные ошибки Директа повторяются по существующим правилам клиента. Объявление без картинки в черновике (картинка ещё рисовалась или черновик старше картинок) получает её при запуске тем же движком. Вариант для проверки создаёт исполнитель командой `StartExperiment`: он копирует `image_id` и хэш исходного объявления и ничего не загружает.

**5. Интерфейс.**
- `AdPreview` показывает картинку (`<img>` по `/api/ad-images/:id`) и кнопку «Другая картинка» рядом с «Изменить» и «Убрать». Пока картинка рисуется, на её месте подпись «Рисуем картинку…».
- «Запустить» сначала сохраняет черновик, чтобы запуск взял объявления и картинки такими, какими их видит владелец.
- `AdsSheet` показывает картинку у объявлений на сайтах-партнёрах.
- Сообщения сбоя и лимита — под картинкой.

## Risks / Trade-offs

- [Модерация Директа может отклонять сгенерированные картинки] → промпт запрещает текст, цифры, логотипы и людей крупным планом. Отклонение идёт обычным путём модерации, контрактный тест проверяет загрузку на тестовом аккаунте.
- [Платные картинки дороже текстов] → лимит на бизнес в месяц, по одной картинке на объявление, «Другая картинка» только по нажатию.
- [Размер и формат картинки для Директа] → квадрат 1024 × 1024 PNG — в пределах стандартных изображений текстово-графических объявлений. Требования проверяются контрактным тестом до релиза.
- [PNG в базе растит её размер] → картинок немного (объявлений на сайтах-партнёрах 1–3 на направление, шаблон ≈60 КБ). Отвергнутые «Другой картинкой» остаются: по ним считается месячный лимит платных картинок. Очистка старых — отдельное изменение, если размер станет заметен.

## Migration Plan

1. `pnpm db:generate --name ad_images`, проверить SQL: новая таблица и новая колонка, без удалений.
2. Выкатить worker, затем web. Старые объявления остаются без картинки (`image_id` пуст) и показываются, как раньше.
3. Откат: прежние образы; таблица и колонка не мешают старому коду.
