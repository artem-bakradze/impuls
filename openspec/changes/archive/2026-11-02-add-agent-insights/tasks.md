## 4. Агент (agent, worker)

- [x] 4.1 Инструменты: `insight` вместо `justification` в инструментах действий, `report_insight`, `get_recent_insights`; расширенный `TurnSnapshot` с перечнем фактов; в `runAgentTurn` проверка инсайта до исполнителя, «Что решили» из ответа исполнителя, сохранение инсайта и `insight_id` у записей истории; проверка — unit-тесты хода на тестовой политике: действие с инсайтом сохранено и связано с историей, инсайт с неизвестным фактом отклонён без действия
- [x] 4.2 Разбор дня: проверка итогового сообщения хода по стоп-листу и числам, `summary_valid`; ход без действий и инсайтов — строка «Посмотрели рекламу — менять ничего не нужно»; проверка — unit-тест
- [x] 4.3 Новая версия инструкций агента: инсайт к каждому действию, наблюдения через `report_insight`, без повторов недавних выводов, разбор дня одним абзацем; тестовые политики (`RandomPolicy`, `AdversarialPolicy`, `ReplayPolicy`) выдают инсайты; признак `decides` у `AgentRuntime` (`false` у `IdlePolicy`); проверка — тесты политик и `pnpm eval:agent --dry-run`
- [x] 4.4 Eval агента: сценарии проверяют, что каждое действие идёт с валидным инсайтом, а итоговые сообщения проходят проверку; проверка — `pnpm eval:agent --dry-run` зелёный; платный прогон — по запросу перед выпуском

## 5. Страховка и инсайты правил (core, worker)

- [x] 5.1 `safetyNet` получает `agentActed` (завершённый ход агента с `decides` за 24 часа) вместо `agentEnabled`; без такого хода правила и запуск проверки действуют сразу (дельта `optimization-engine`); проверка — unit-тесты core и BDD «Agents API недоступен двое суток»: решения правил в тот же день
- [x] 5.2 Инсайты правил: `renderInsight` для `SAFETY_*`, `EXPERIMENT_*`, пауз и возобновлений защиты бюджета, без `BUDGET_FIT`; инсайт создаётся после ответа исполнителя и связывается с записью истории; разбор дня без хода — «Сегодня решения принимали страховочные правила» с причиной; проверка — unit-тесты шаблонов и BDD «Правило сработало вместо агента», «Подстройка лимита — не инсайт»

## 6. Симуляция с агентом (worker)

- [x] 6.1 `simulationWorld` берёт агента из базового контекста, `launchSimulation` не выключает флаг; лимит затрат на прогон; скрытая правда сценария не попадает в снимок; проверка — unit-тест: ход агента в симуляции по виртуальному времени, в перехваченном контексте нет правды сценария
- [x] 6.2 Время стоит, пока агент думает: после часа с ходом `advanceWorld` прерывается, а `lastTickAt` сдвигается на реальное время хода; статус пульта `agentTurn`; тикер ведёт тик каждой симуляции отдельно и не начинает новый, пока идёт прежний; проверка — unit-тесты на фиктивных часах: медленный ход одной симуляции не задерживает другую, реальное время хода не превращается в виртуальное
- [x] 6.3 «Начать заново» с агентом: подтверждение предупреждает, что решения могут отличаться; с тестовой политикой прогон повторяется точно; проверка — unit-тест воспроизводимости на `ReplayPolicy` и тест подтверждения
