## Purpose

Регистрация и вход владельца бизнеса через аккаунт Google без паролей, управление сессией и удаление аккаунта со всеми данными.

## ADDED Requirements

### Requirement: Вход через Google
The system SHALL позволять регистрироваться и входить только через Google OAuth 2.0 / OpenID Connect. При первом входе аккаунт создаётся автоматически по email и имени из профиля Google, без дополнительных форм.

#### Scenario: Первый вход нового пользователя
- **WHEN** пользователь без аккаунта нажимает «Войти через Google» и подтверждает доступ
- **THEN** система создаёт аккаунт с email и именем из Google и открывает первый шаг мастера запуска

#### Scenario: Повторный вход
- **WHEN** пользователь с существующим аккаунтом входит через Google
- **THEN** система открывает главный экран (сводку), если реклама уже запускалась, иначе шаг мастера, на котором пользователь остановился

#### Scenario: Пользователь отменил вход
- **WHEN** пользователь отказывается предоставить доступ на экране Google
- **THEN** система возвращает его на стартовую страницу с сообщением «Вход отменён. Чтобы продолжить, войдите через Google ещё раз» и не создаёт аккаунт

### Requirement: Сессия
The system SHALL поддерживать сессию 30 дней с момента последней активности и SHALL предоставлять выход из аккаунта. Cookie сессии MUST быть HttpOnly, Secure и SameSite=Lax.

#### Scenario: Истечение сессии
- **WHEN** пользователь не заходил больше 30 дней
- **THEN** при следующем открытии система просит войти заново, а реклама продолжает работать по текущим настройкам

#### Scenario: Выход
- **WHEN** пользователь нажимает «Выйти»
- **THEN** сессия становится недействительной на сервере, а повторный запрос со старой cookie получает переадресацию на страницу входа

### Requirement: Удаление аккаунта
The system SHALL позволять удалить аккаунт. Перед удалением система MUST остановить все кампании, созданные сервисом, отозвать сохранённые OAuth-токены и затем удалить персональные данные пользователя не позднее чем через 30 дней.

#### Scenario: Удаление с активной рекламой
- **WHEN** пользователь подтверждает удаление аккаунта при работающих кампаниях
- **THEN** система останавливает кампании в Директе, отзывает токены, сообщает «Реклама остановлена, данные будут удалены» и выходит из аккаунта
