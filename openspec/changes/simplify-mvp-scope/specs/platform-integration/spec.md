## MODIFIED Requirements

### Requirement: Структура создаваемых кампаний
The system SHALL создавать в Директе для каждого «направления» отдельную кампанию. Направление — это пара «группа услуг × канал»; каналы — «Поиск» и «Сайты-партнёры» (РСЯ). Кампания направления «Поиск» MUST показываться только в поиске, кампания направления «Сайты-партнёры» — только на сайтах-партнёрах. Каждой кампании SHALL назначаться:
- зона показа: регион Директа, соответствующий городу бизнеса;
- расписание по часам работы бизнеса;
- цели Метрики;
- лимит расходов, выставленный `budget-guard`;
- мониторинг доступности сайта: площадка приостанавливает показы, если посадочная страница не открывается.

Внутри каждой кампании система SHALL создавать группу объявлений с зоной показа кампании. Для направления «Поиск» группа MUST содержать хотя бы одну ключевую фразу и минус-фразы из `ad-creatives`; без ключевых фраз поисковое направление MUST NOT создаваться. Каждое объявление MUST вести на собственный сайт бизнеса со ссылкой, размеченной UTM-метками сервиса, по которым обращения сопоставляются с направлением и объявлением.

Стратегия с оплатой за обращения SHALL назначаться только вместе с целью Метрики, по которой считаются обращения, и целевой стоимостью обращения, равной ЦСО из `optimization-engine`. Если у бизнеса нет цели Метрики, команда на эту стратегию MUST отклоняться с причиной «нет цели для подсчёта обращений», а кампания остаётся на прежней стратегии.

Доступность сайта проверяет мониторинг Директа. Собственной периодической проверки посадочных страниц сервис MUST NOT выполнять. Остановку показов мониторингом сервис SHALL узнавать из статусов кампаний при сверке и показывать на сводке. Все кампании, созданные сервисом, MUST помечаться так, чтобы сервис отличал их от кампаний, созданных пользователем вручную. Кампании, созданные не сервисом, MUST оставаться нетронутыми.

#### Scenario: В аккаунте уже есть ручные кампании
- **WHEN** у пользователя в Директе есть кампании, созданные не сервисом
- **THEN** система их не изменяет, не останавливает и не учитывает в бюджете сервиса, а на шаге подключения предупреждает, что их расходы не входят в бюджет сервиса

#### Scenario: Посадочная страница не открывается
- **WHEN** сайт пользователя перестал открываться, и Директ приостановил показы мониторингом
- **THEN** не позднее следующей сверки сводка показывает «Ваш сайт не открывается — показы приостановлены, чтобы не тратить деньги впустую», а письмо не отправляется

#### Scenario: Город бизнеса
- **WHEN** пользователь запускает рекламу с городом «Казань»
- **THEN** все кампании сервиса и их группы создаются с регионом «Казань» из справочника регионов Директа

#### Scenario: Запуск поискового направления
- **WHEN** пользователь запускает направление «Маникюр — Поиск» с 12 ключевыми фразами, 5 минус-фразами и двумя объявлениями
- **THEN** в Директе появляется кампания с показами только в поиске, одной группой с регионом города бизнеса, 12 ключевыми и 5 минус-фразами и двумя объявлениями, ссылки которых ведут на сайт бизнеса с UTM-метками этого направления и объявления

#### Scenario: Запуск направления «Сайты-партнёры»
- **WHEN** пользователь запускает направление «Маникюр — Сайты-партнёры»
- **THEN** в Директе появляется кампания с выключенными показами в поиске и включёнными на сайтах-партнёрах, а ключевые фразы для её запуска не требуются

#### Scenario: Поисковое направление без ключевых фраз
- **WHEN** для направления «Поиск» не подобрано ни одной ключевой фразы
- **THEN** кампания не создаётся, а пользователь видит «Не получилось подобрать поисковые запросы для этой услуги — уточните описание услуги»

#### Scenario: Стратегия с оплатой за обращения без цели Метрики
- **WHEN** агент предлагает перевести направление на оплату за обращения, а у бизнеса нет цели Метрики
- **THEN** команда отклоняется с причиной «нет цели для подсчёта обращений», стратегия кампании в Директе не меняется, а в журнале хода записан отказ
